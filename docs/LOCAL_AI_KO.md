# 내 PC에서 시각 모델로 사진 읽기 (0.6.0)

기존 OCR·색상·도형 규칙 대신 **이미지 전체를 이해하는 로컬 시각 모델**을 사용하는 모드입니다. Ollama에서 `qwen2.5vl:7b`를 실행하고, 앱은 그 모델에 사진과 자동으로 찾은 카드 확대 영역을 전달합니다. 확대 영역을 못 찾아도 원본 전체로 판독을 시도합니다. 카드 정답 등록이나 Tesseract 설치는 필요 없습니다.

이 채팅과 동일한 모델을 PC에 복제한 것은 아닙니다. 작은 로컬 모델은 글자·무늬·작은 숫자를 잘못 읽거나 JSON 응답을 완성하지 못할 수 있습니다. **이 릴리스에서는 실제 모델과 사용자 원본 사진의 정확도를 검증하지 못했습니다.** 자동 테스트는 연결·응답 검증·UI·취소 동작에 관한 것으로 실제 인식 성공률을 뜻하지 않습니다.

## 1. 준비

- 기존 Python **3.12 64비트**와 앱 실행 환경을 유지합니다. Python 3.14로 바꿀 필요가 없습니다.
- 모델에는 수 GB 이상의 저장 공간과 상당한 메모리가 필요합니다. 시스템 RAM 16GB 이상과 충분한 메모리의 GPU를 권장하지만, 적합성은 실행 중인 프로그램·입력 크기에 따라 달라집니다. CPU만으로도 시도할 수 있으나 수십 초~수 분이 걸릴 수 있습니다.
- 최초 Ollama·모델·Python 의존성 설치에는 인터넷이 필요합니다. **사진 인식 요청은 `127.0.0.1:11434`로만 전송**합니다. 외부 API, 키, 사용량 요금, 클라우드 대체 호출은 없습니다. 앱이 외부 사이트에서 카드를 가져오는 방식이 아닙니다.

## 2. Ollama와 모델 설치 (한 번)

1. [Ollama Windows 설치 페이지](https://ollama.com/download/windows)에서 설치 파일을 받아 설치합니다.
2. 설치한 **Ollama 앱을 실행**합니다. 보통 백그라운드에서 동작합니다.
3. 프로젝트의 **`setup_local_ai.bat`**를 더블클릭해 모델을 받습니다. 다운로드 완료까지 창을 닫지 마세요.
4. 직접 설치하려면 새 PowerShell 창에서 아래를 실행합니다.

```powershell
ollama pull qwen2.5vl:7b
ollama list
```

`ollama list`에 `qwen2.5vl:7b`가 보이면 준비됐습니다. 명령어를 찾지 못하면 설치 후 PowerShell을 새로 열거나 `setup_local_ai.bat`를 사용하세요. 연결 실패면 Ollama 앱이 실행 중인지 확인하세요. 필요하면 별도 PowerShell에서 `ollama serve`를 실행한 채 유지합니다. 이미 서버가 떠 있을 때는 두 번째 서버를 시작하지 마세요.

메모리가 부족하면 다음으로 더 작은 모델을 받을 수 있습니다. 판독 정확도는 더 낮을 수 있습니다.

```powershell
ollama pull qwen2.5vl:3b
```

이 경우 앱의 **화면 설정 → Ollama 시각 모델**을 `qwen2.5vl:3b`로 바꾸세요. 현재 선택 가능한 모델은 위의 7b/3b 두 로컬 모델입니다. 클라우드 모델 이름과 일반 텍스트 전용 모델은 받지 않습니다.

## 3. 실제로 찍은 사진부터 확인

1. `run_windows.bat`를 실행합니다. 제목의 **0.6.0**을 확인합니다.
2. **화면 설정 → 로컬 AI로 실제 사진 읽기**를 누릅니다.
3. 본인이 저장한 원본 PNG/JPG를 선택합니다. 모의 이미지로 대체하지 않습니다.
4. **플레이 보기**에서 내 카드·보드·팟·스택·상대 수를 사진과 대조합니다. **좌석·베팅** 탭은 폴드와 OFFLINE을 구분해 보여줍니다.
5. 첫 모델 로딩과 사진 판독을 기다립니다. 같은 사진은 프레임마다 모델에 다시 보내지 않습니다. 출력 형식·금액·카드·참여 여부 검증에 실패하면 이유를 표시하고 계산을 보류합니다. 카드만 확정됐다면 카드만 표시합니다.

이 채팅에서 사용자가 제시한 대표 정답은 **6♦ K♦ / 보드 없음 / 총 팟 140**과 **8♠ 5♠ / 보드 없음 / 총 팟 230 / 현재 상대 4명**입니다. 이 값은 사람이 사진을 읽은 대조 기준이며, 코드가 정답을 하드코딩해서 출력하지 않습니다.

## 4. 화면을 계속 읽기

사진 판독이 맞는지 확인한 뒤 **로컬 AI로 내 화면 분석 시작**을 누르세요. 선택한 모니터를 캡처하고 앱 자체 창을 가린 뒤 로컬 모델로 읽습니다. 영역 보정은 필요 없고 모니터 번호는 확인해야 합니다. 탭·주소창이 포함된 전체 화면도 입력할 수 있습니다. 작은 분석창은 카드/이름을 가리지 않는 곳으로 옮기세요.

최소 판독 간격은 기본 **5초**이며 5~60초로 설정합니다. 실제 간격은 모델이 처리하는 시간보다 빨라질 수 없습니다. UI는 별도 스레드로 동작하고, 중지 버튼은 대기 중인 연결도 닫습니다.

로컬 결과에는 **몇 초 전 캡처 기준인지** 표시합니다. 판독 중 화면 픽셀이 바뀌면 그 결과를 캡처 시점의 스냅샷으로 표시하고 **현재 콜·행동 금액 판단은 보류**합니다. 따라서 시계/애니메이션이 계속 바뀌는 라이브 화면에서는 행동 판단이 자주 보류될 수 있습니다. 계산된 팟 지분도 현재가 아닌 표시된 캡처 시점의 카드·상대 수에 대한 추정입니다. 아주 오래 응답이 없으면 이전 결과를 제거합니다.

## 5. 오류를 볼 때

- **Ollama 연결 실패/시간 초과:** Ollama 실행, 모델 설치, PC 메모리를 확인합니다. 첫 CPU 판독이 180초를 넘으면 요청이 시간 초과될 수 있습니다.
- **모델이 없습니다:** `ollama pull qwen2.5vl:7b`를 실행하거나 설치한 모델 이름을 입력합니다.
- **AI 응답 필드/JSON 오류:** 사용한 모델이 이미지와 JSON 형식을 지원하는지 확인합니다. 판독 실패를 실제 카드 값으로 바꾸지 않습니다.
- **총 팟/스택/참여 여부 미확인:** 모델이 그 값을 확정하지 못한 것입니다. 현재 프레임의 읽은 카드만 표시할 수 있고 전체 계산은 보류됩니다.
- **틀린 패를 읽음:** 모델도 잘못 읽을 수 있습니다. 원본 사진과 판독값을 대조하세요. 원본 파일과 오류/판독 결과가 있어야 해당 사례를 실제 모델로 검증할 수 있습니다.

CLI로 사진 한 장을 읽으려면 다음을 사용합니다.

```powershell
.\.venv\Scripts\python.exe -m src.main --analyze "C:\사진\table.png" --local-ai --model qwen2.5vl:7b
```

이 호출도 로컬 Ollama만 사용합니다. 사진·응답·닉네임은 앱이 파일에 자동 저장하지 않습니다. 외부 사이트 API/DOM/패킷 접근이나 자동 클릭·베팅 기능은 없습니다.
