# 처음 사용하는 분을 위한 Windows 실행 안내

## 먼저 알아둘 점

Codex Cloud는 코드를 만드는 원격 Linux 컴퓨터입니다. 그곳에서 실행한 프로그램은 내 PC의 브라우저를 볼 수 없습니다. 이 앱을 **내 Windows PC에 내려받아 실행**해야 내 화면을 캡처할 수 있습니다. 사이트 URL을 넣는 것만으로 카드를 읽는 제품은 아닙니다. 실제 테이블 배치와 카드 그림을 등록하는 **화면 보정**이 필요합니다.

이전 버전의 모의 화면 분석에 실제 화면 캡처 경로를 추가한 개발 버전입니다. 사이트의 허가 여부를 확인한 것이 아니며, 공식 PokerNow 연동이나 완성된 범용 카드 인식기를 제공하는 것은 아닙니다. 자동 클릭·베팅, DOM·API·네트워크 패킷 접근은 없습니다.

## 1. 프로그램 파일을 내 PC로 가져오기

1. [GitHub 실행용 코드 ZIP 다운로드](https://github.com/Wonybott/holdem/archive/refs/heads/main.zip)를 누릅니다. 비공개 저장소라면 먼저 GitHub에 로그인하세요.
2. 내려받은 ZIP을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택합니다.
3. 압축을 푼 폴더 안에 `run_windows.bat`, `README.md`, `requirements.txt`, `src` 폴더가 보이는지 확인합니다. ZIP 안에서 바로 실행하면 안 됩니다.
4. 직접 GitHub에서 받으려면 https://github.com/Wonybott/holdem 에서 **Code → Download ZIP**을 선택합니다. 압축을 풀면 보통 `holdem-main` 폴더가 생깁니다.

권장 위치는 `C:\Users\내이름\Downloads\holdem-vision-analyzer` 같은 쓰기 가능한 폴더입니다. `Program Files` 안에 옮길 필요는 없습니다.

## 2. Python 설치 (처음 한 번)

1. https://www.python.org/downloads/windows/ 에서 **Python 3.12 64비트** 설치 파일을 받습니다.
2. 설치 화면에서 **Add python.exe to PATH**를 체크합니다. Python Launcher(`py`)도 함께 설치합니다.
3. 설치가 끝나면 프로그램 폴더의 **run_windows.bat**를 더블클릭합니다.
4. 첫 실행에는 필요한 라이브러리를 인터넷에서 설치하므로 시간이 걸립니다. 검은 창이 열린 채로 유지되는 것은 정상입니다. 설치 후 앱 창이 열립니다. 검은 창을 닫으면 앱도 종료될 수 있으니 실행 중에는 유지하세요.
5. 다음 실행에도 같은 파일을 더블클릭하면 됩니다. Python이나 패키지를 일일이 다시 설치할 필요는 없습니다.

`Python 3.12 is required`가 나오면 Python 3.12와 Launcher 설치를 확인하세요. 다른 오류가 나오면 검은 창의 오류 메시지를 알려주면 됩니다. 이 파일은 관리자 실행을 요구하지 않습니다. OS가 다운로드한 파일의 실행 경고를 보여주면 출처와 내용을 확인하세요.

### 명령어로 실행하고 싶다면

`README.md`가 있는 폴더를 열고 탐색기 주소창에 `powershell`을 입력한 뒤 Enter를 누릅니다. 다음을 한 줄씩 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.main
```

가상환경 활성화나 PowerShell 실행 정책 변경은 필요 없습니다. 이미 설치했다면 마지막 줄만 실행합니다.

## 3. 먼저 모의 화면으로 정상 실행 확인

1. 상단 모드는 **자체 모의 화면**으로 둡니다.
2. **모의 창** → **시작 / 캡처 재개**를 누릅니다.
3. 간격 기본값은 **1000ms = 1초**입니다. 동일 상태를 두 프레임에서 확인하므로 최초 결과는 보통 1초와 계산 시간 이후 나옵니다.
4. **새 모의 패**를 눌러 카드·팟과 분석 결과가 바뀌는지 봅니다.
5. **중지**를 누르면 캡처와 계산이 멈추고 이전 분석 결과가 지워집니다.

## 4. 실제 화면 숫자 OCR 설치 (실제 화면 모드만)

모의 화면은 추가 설치 없이 됩니다. 실제 화면의 팟·콜 숫자를 읽으려면 **Tesseract OCR**이라는 별도 Windows 프로그램이 필요합니다. 무거운 AI 모델을 다운로드하지는 않습니다.

Windows 터미널에서 설치하려면 다음 명령을 사용합니다.

```powershell
winget install --id UB-Mannheim.TesseractOCR -e
```

패키지를 찾을 수 없거나 winget이 없으면 https://github.com/UB-Mannheim/tesseract/wiki 에 안내된 Windows 설치 방법을 확인하세요. 기본 설치 위치 `C:\Program Files\Tesseract-OCR`를 유지하고 **영어(eng) 데이터**를 설치합니다. 실행 파일은 `tesseract.exe`여야 합니다. 앱은 PATH 또는 이 기본 경로에서 찾습니다. 설치 뒤 앱을 다시 실행하세요.

## 5. 실제 PokerNow 화면 설정

**캡처 경로는 구현됐지만, 실제 PokerNow 스크린샷으로 검증한 기본 인식 프로필은 아직 없습니다. 처음에는 아래 보정이 필요합니다.** 사이트의 테마·브라우저 줌·창 크기가 달라지면 다시 보정해야 합니다.

1. 브라우저에서 플레이 중인 테이블을 엽니다. 브라우저 줌과 창 크기를 고정합니다. 되도록 전용 모니터에서 앱이 테이블을 가리지 않게 배치하세요. 화면 가림은 인식 실패나 오인식의 원인이 됩니다.
2. 앱 하단의 **상대 수, 스택, 포지션**을 실제 상황에 맞게 입력합니다. 자동 탐지되는 값이 아닙니다. 스택은 나 먼저, 상대 순서로 입력하며 상대 수+1개가 필요합니다. 보정 화면에서 스택 영역을 따로 지정하면 그 스택만 OCR로 갱신합니다.
3. 앱 상단의 **캡처 모니터 번호**를 선택합니다. 일반 PC는 1입니다. 여러 모니터에서 번호가 다르면 다시 선택해 확인합니다.
4. **실제 화면 캡처·보정 (1.5초 뒤)**을 누릅니다. 앱/모의 창이 숨겨지고 1.5초 후 선택한 모니터를 한 번 캡처합니다. 이 사이 브라우저 테이블을 앞으로 가져옵니다. 캡처된 이미지는 보정 대화창에 표시되며 자동 서버 전송하지 않습니다.
5. 보정창 상단의 대상이 **먼저: 테이블 전체 선택**일 때, 그림 위에서 테이블 영역을 드래그합니다. 캡처 범위가 이 테이블로 제한됩니다.
6. 대상 목록에서 `홀 카드 1 (card0)`을 선택합니다. **정답 선택** 목록에서 실제 보이는 카드, 예를 들어 `As`를 고른 뒤 카드의 숫자와 무늬가 함께 들어가는 영역을 드래그합니다. 두 번째 홀 카드도 반복합니다. 다른 카드와 비교할 수 있게 각 카드의 같은 부분을 같은 비율로 지정하세요.
7. `보드 1~5 (card2~card6)`도 모두 지정합니다. 비어 있는 보드 자리는 정답을 **보드 빈 칸**으로 선택해서 등록합니다. 빈 칸은 위치마다 따로 등록합니다.
8. `팟 숫자만`, `콜 숫자만`을 각각 선택한 뒤 **숫자만** 드래그합니다. 통화 기호/버튼 문구는 제외합니다. 콜 숫자가 표시되지 않는 상황은 현재 자동 처리하지 못합니다. 금액 0을 임의로 가정하지 않고 실패로 표시합니다.
9. 필요한 스택 숫자 영역도 선택합니다. 생략한 스택은 2번에서 입력한 값을 고정 가정으로 사용합니다.
10. **Save**로 저장합니다. 앱 설치 폴더의 `.local/screen-profile.json`에 보정 좌표와 카드 샘플만 저장합니다. 전체 화면은 자동 저장하지 않습니다.
11. 모드가 **PokerNow / 실제 화면**인지 확인하고 **시작 / 캡처 재개**를 누릅니다. 선택한 테이블 영역을 목표 간격 1초로 계속 읽습니다. 상대 범위는 기본 `random`이며 원하는 범위를 입력하고 **분석 설정 적용**으로 바꿀 수 있습니다.

### 새 카드가 나와 '인식 실패'가 뜨면

첫 보정에서 본 카드만 샘플이 등록됩니다. 현재 버전은 모든 카드 그림을 미리 갖고 있지 않습니다. 새 카드가 나오면 **실제 화면 캡처·보정**을 다시 열어 해당 카드 영역과 정답을 등록합니다. 같은 모니터 설정이면 기존 영역/샘플을 보존합니다. 보드가 채워진 경우에는 앞서 등록한 빈 칸과 같은 크기/위치의 카드 영역을 사용하세요. 잘못 등록한 샘플은 **카드 샘플 모두 지우기**로 초기화하고 재등록할 수 있습니다.

이 과정이 번거로우면 실제 테이블 스크린샷을 개발자에게 제공해 기본 템플릿과 배치 프로필을 만드는 추가 작업이 필요합니다. 현재 상태를 'PokerNow에서 모든 카드를 즉시 인식하는 완성품'으로 취급하면 안 됩니다.

### 화면/게임 구성이 바뀌면

- 브라우저 이동·창 크기·줌 변경: 테이블 및 필드 영역을 다시 지정하세요.
- 모니터 해상도/배치 변경: 캡처가 중단됩니다. 모니터를 확인하고 다시 보정하세요.
- 상대 수/포지션/수동 스택 변경: 입력을 고친 뒤 보정을 다시 저장하세요. 자동 추적하지 않습니다.
- 모니터에 앱이 테이블을 가림: 앱을 옆으로 옮기세요. 같은 모니터에서는 '항상 위' 옵션을 끄는 편이 좋습니다.
- OCR 실패: 숫자를 선명하게 표시하고 필드에 숫자만 들어가게 다시 지정하세요. 원본/확대 판독이 불일치하거나 신뢰도가 낮으면 값이 버려집니다. OCR이 항상 맞는 것은 아니므로 화면과 비교하세요.

## 6. 결과와 1초 갱신의 의미

캡처 간격은 기본 1000ms이며 **목표 간격**입니다. 두 프레임 안정화, OCR, Monte Carlo 계산이 필요하므로 결과가 반드시 매초 새로 완성되는 것은 아닙니다. 처리 시간이 길면 다음 프레임을 늦추며 작업을 중첩하지 않습니다. 부담이 크면 표본 수를 1000~3000으로 낮추세요. 같은 상태는 재계산하지 않고 표시를 유지합니다.

승률은 지정한 상대 범위에 대한 추정값입니다. 기대 팟 지분에는 무승부 분배를 반영합니다. 콜 EV는 추가 베팅 없이 쇼다운한다는 가정이며 사이드 팟/레이크는 반영하지 않습니다. 상대 행동·폴드 확률을 모르면 특정 행동과 베팅액을 확정 추천하지 않습니다. 불확실하거나 오래된 결과는 실패/갱신 필요로 표시합니다.

## 7. 종료 및 문제 보고

**중지**로 캡처를 멈춘 후 앱을 닫으면 됩니다. 클릭 통과는 10초 뒤 자동 해제됩니다. 문제가 있으면 운영체제, 화면 배율, 브라우저 줌, 오류 메시지와 함께 테이블 화면을 알려주세요. 이 프로그램은 관리자 권한, 계정 비밀번호, 사이트 API 키를 요구하지 않습니다.
