## 클라우드 자동 검증

`QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`

포커 족보, 고정 너츠 승리/패배, 프리플롭 AA의 승률, 2/3/9인 공동 쇼다운 팟 분배, 중복/불법 입력, 범위 충돌, 취소, 팟 오즈/조건부 EV, 모의 PNG와 전체 52장, 숫자 훼손, 빈 이미지/부분 ROI, 여러 단계/포지션, 분수 확대, 안정화 무효화, 실제 스레드의 재시도·정지·재시작, GUI 타이머 응답성, 오래된 계산 거부를 검사한다. 타이머 검사는 실제 Monte Carlo 계산을 수행하는 동안 Qt 이벤트가 처리되는지 확인한다.

이 테스트는 실제 사이트나 Windows 캡처를 실행하지 않는다. offscreen 클릭 통과 테스트는 Qt 플래그/자동 복구 타이머만 확인한다. 테스트는 API 기본 확률의 정답 근사 범위를 확인하며 수익성을 증명하지 않는다.

## Windows 수동 확인 (아직 미실행)

3. 카드와 팟을 수정해 수동 분석. 중복 카드는 오류, 새 숫자에는 새 분석이 표시되는지 확인. 캡처 재개 시 수동 입력이 해제되는지 확인.
4. 전체 ROI/잘린 ROI/복원을 반복하고 불확실한 프레임에서 이전 결과가 남지 않는지 확인.
5. Windows mss를 켜고 시작한 후 모의 창을 클릭. 읽힌 값과 화면을 비교. 모의 창을 최소화하거나 다른 창을 앞으로 옮겨 실패/재시도, 다시 클릭해 복구되는지 확인.
6. 화면 배율 100/125/150/200%, 창 이동/크기 변경/서로 다른 DPI 모니터 사이 이동을 확인. 축소·가림으로 구분 불가하면 추측 대신 실패해야 한다. 라이브 캡처의 물리적 DPI 처리는 자동 이미지 테스트와 별도로 확인해야 한다.
7. 항상 위 옵션, 클릭 통과 후 클릭이 통과되는지 및 10초 후 복구되는지 확인. 다른 프로세스의 자동 입력은 하지 않는다.
8. 표본 수를 50000으로 올려 계산 중 창을 이동하고 버튼을 눌러 응답성을 확인. 중지 직후 재시작, 계산 중 종료를 반복해 프로세스가 남지 않는지 확인.

저해상도 축소나 소수점 배율의 보간/압축으로 판독 실패하면 원래 크기 이상으로 키우거나 PNG를 사용한다. 폰트/테마가 다른 일반 테이블을 인식하지 않는 것은 의도된 제한이다. 네이티브 기능은 수동 점검 완료 전 검증된 것으로 취급하지 않는다.
